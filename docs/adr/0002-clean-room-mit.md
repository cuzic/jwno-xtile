# 0002. MIT で公開し、GPL の jwno-layout-tall は「参照のみ・独立再実装」として扱う

- 状態: Accepted（Opus レビュー 5 回で収束、2026-10-31。公開前チェックと作者への打診は未実施）
- 日付: 2026-10-31

## Context

目標は MIT ライセンスの成果物。Jwno 本体は MIT。参考にしたい jwno-layout-tall は
**GPL-3.0**（`LICENSE` で確認）。コードを流用・翻案すると MIT で配布できない。
著作権は表現を保護しアイデアは保護しないが、境界は曖昧になりやすい。

**事実として**: 本調査の中で、実装担当と同じエージェントが jwno-layout-tall の全 4 ファイルを
読んだ。したがって厳密な意味でのクリーンルーム（仕様担当と実装担当の分離）ではない。
そのためタイトルは「独立再実装」とし、「クリーンルーム」とは呼ばない。

## Considered Options

1. 設計のみ参考にして自前で実装し、独立性を示す記録を残す。
2. 作者に MIT / デュアルライセンスでの提供を依頼する。
3. GPL で公開する。

## Decision

案 1 を採り、**案 2 を公開前に実施する**（費用が低く効果が大きい。回答が得られれば
リスクが消える）。

- GPL コードは写さない。一次情報は xmonad の仕様（StackSet）と Jwno の MIT コード。
- **ref はリポジトリの外に置く**: `~/jwno-xtile-ref/jwno`（MIT の Jwno のみ。tall は削除済み）。リポジトリ内に
  GPL コードを置かない（`git add .` での混入防止、エージェントが作業ディレクトリを
  grep して GPL コードを取り込むのを防止）。`.gitignore` に `ref/` も入れてある。
  **tall の checkout は削除した**（ユーザー判断、2026-10-31）。再度 clone しない。
- 構造の違いを記録する: 参照元は Jwno の Frame を直接操作する手続き的コード、本実装は
  リストと純関数による状態遷移＋矩形出力で、構造が根本的に異なる（レビューでも確認）。
- プロジェクト名: 旧名 `jwno-xmonad-like` は GPL リポジトリのファイル名 `xmonad-like.janet` と同じ語を含み、
  派生物と誤解される外観リスクがあったため、**`jwno-xtile` に改名した**（ユーザー判断、2026-10-31）。
- 外部由来の知見（Firefox でフォーカスが遅れる、`EnumChildWindows` のコールバック内で
  Jwno を呼ばない）は「事実」として出典付きで記録する。
- **NOTICE を維持する**: xmonad（BSD-3-Clause）は `test/xmonad-model.janet` が
  `StackSet.hs` の転記であるため全文を掲載済み。Jwno のコードを複製した場合は
  その著作権表示を追加する。VirtualDesktopAccessor のライセンスは未確認で、
  配布前に確認する。

## Consequences

- 「読んでしまった」事実は消えない。独立性は、構造の差異の記録と、作者への打診で補強する。
- 配布物には NOTICE が必須。

## 独立性の記録（2026-11-01）
`docs/references/jwno-ecosystem.md`（Opus による公開情報の調査）によると、jwno-layout-tall の PR #1 の説明文には、「起動時に既に開いている窓を登録する」「Jwno の現在のフレームより OS の前面の窓を信用する」がある。
本プロジェクトは同じ結論に、実機の契約テストの失敗（`docs/spike/2026-11-01-real-machine.md` の発見 1。CT-3 の失敗から Jwno のソース `win.janet` の読解で原因を特定）と ADR 0005 の観測原則から、独立に到達した。
PR #1 の記述を読んだのは、この調査が初めてで、実装（`adopt-existing!`）の後である（コミット履歴で確認できる）。調査はソースコードを読まず、README・PR の説明・コミットメッセージの要旨に限った。
